# CS2 Insight Agent 可选天空盒资源包

主程序只内置 Cartoon 系列，以控制安装包体积。本资源包包含其余 27 个天空盒，按需导入即可，无需把整个资源包复制到程序目录。

## 使用方法

1. 解压本资源包。
2. 可先在 `previews/` 查看同名预览图，再打开 CS2 Insight Agent 的“设置 → 游戏资源 → 天空盒资源”。
3. 点击“添加天空盒”，填写显示名称。
4. 在 `skyboxes/<天空盒名称>/` 中同时选择该目录下的 `.vmat_c` 和 `.vtex_c` 文件。
5. 点击“校验并上传”。成功后即可在录制或高级播放弹窗中选择。

导入后的文件保存在用户数据目录，不会因主程序更新而丢失。只导入实际需要的天空盒，可以避免占用额外磁盘空间。

## 包含内容

- `chroma_green`、`chroma_blue`：纯绿幕、纯蓝幕
- `xuejing`、`yinhezhanjian`、`huoshaoyun`、`xiyang`、`chengchetiankong`
- Egg 系列：`egg1`–`egg15`、`egg23`–`egg27`

每个子目录必须成对使用其中的材质文件与纹理文件，不能跨目录混用。
