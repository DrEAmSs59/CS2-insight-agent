# VPK 选项隔离与恢复检查

日期：2026-09-26。检查对象：当前本地 `develop` 工作区，以及本机安装的 CS2 资源。

## 结论

发现并修复了 5 类问题。当前前端可选功能的参数传递、包内资源组合、临时地图替换和恢复流程已通过下述验证。

**POV 关闭后，天空盒、打蜡和下雨不应带入 POV 样式。语音和按键 HUD 是独立选项，保持开启时仍需要一个辅助 HUD 包；它们也关闭时，纯画面效果包不包含 Panorama HUD 资源。**

自动化审计确认的是选项、真实资源构建和恢复逻辑。随后用户完成手动录制测试并确认无异常；这不代表下文所有组合的游戏内画面和音频均已逐项实测。

## 已修复的问题

| 问题 | 原来的实际风险 | 修复 |
| --- | --- | --- |
| POV 关闭时仍运行部分 POV 逻辑 | 仅开语音或按键 HUD，脚本仍隐藏原生聊天/无线电区域，并运行重建的消息流 | 统一按当前录制的 POV 开关判断；高级播放继续按运行时 HUD 模式判断。已重新生成两份编译 VPK 模板 |
| 蓝绿幕与天气一起使用时遗漏粒子 | 蓝绿幕外层包先写入临时文件，后追加的雨滴/雪粒子没有进入最终安装文件 | 所有图层合成完成后再输出临时 VPK、计算哈希并安装 |
| “默认/关闭”未覆盖旧参数 | 请求的顶层选项已恢复默认，旧 `warmup` 中的天空盒、材质或天气仍可能生效 | 默认值也明确覆盖旧 `warmup`，再交给录制器 |
| 全关录制未清理历史残留 | 上一场异常留下的 VPK 可能在下一次全关录制时继续被加载 | 无新效果的录制也先检查并恢复残留；恢复失败时禁止启动 |
| 非 POV 资源恢复失败被漏报 | 仅语音/按键 HUD 的恢复结果缺少统一 VPK 状态；天空盒/天气等失败也可能被前端按 POV 开关忽略 | 所有 VPK 会话统一返回恢复证据；中断、停止和结果界面均检查它，不再仅依据 POV 开关 |

主要修改：`backend/app/pov_hud_manager.py`、`backend/app/obs_director.py`、`backend/app/recording/api.py`、`pov/voice_hud_injection.js`，以及前端恢复提示与回归测试。

## 功能范围和预期行为

| 功能 | 检查结果与加载行为 |
| --- | --- |
| 所有相关选项关闭 | 不安装新 VPK；已有的托管残留先恢复 |
| POV HUD | 使用逐 Demo 生成的 POV 模板；录制入口要求生成成功，失败时不以旧场次/静态内容继续录制 |
| 语音 all/team/enemy/mute、按键 HUD 与位置 | 独立于 POV；辅助模式使用不含 POV 雷达/队伍栏编译样式的模板，payload 明确关闭 POV 视觉功能 |
| 普通/自定义天空盒 | 只加入所选天空材质、纹理、当前地图映射及必要的太阳遮罩；自定义资源有格式和哈希校验 |
| 打蜡 | 只加入当前地图对应材质；可以与天空盒、POV 或辅助 HUD 组合 |
| 下雨 | 加入对应地图的雨天地面方案、天空/环境后处理和雨滴粒子，并临时替换已校验的主地图 VPK；可与显式选择的天空盒组合 |
| 蓝/绿幕 | 临时替换已校验的子天空盒 VPK，并为播放副本准备天空引用；与下雨组合时，同时管理主地图和子天空盒的备份/恢复 |
| 高级播放 | 保留高级控制菜单；HUD 模式热切换使用运行时开关，避免 POV 固定样式留在原生观战模式中 |
| 普通播放、昵称副本 | 普通播放先清理历史资源；昵称修改作用于 Demo 副本，不会单独打开 POV 或天气 |
| 跨 Demo 队列、失败、停止、意外退出 | 先停止游戏并验证恢复，再构建下一场；文件锁、构建失败、地图不匹配、外部修改和哈希不匹配均有拒绝继续或恢复失败的路径 |
| 安装/发布资源 | 开发模式读取当前工作区。正常桌面打包脚本会重新暂存资源；现有 `frontend/src-tauri/bundle-resources/pov` 是旧暂存副本，不能当作本次修复后的成品 |

这些功能通常合并到一个名为 `csgo/pov.vpk` 的外层包。这个文件名本身不表示启用了 POV。雨天和蓝绿幕还会分别管理主地图/子天空盒的临时替换文件。

## 支持范围与现有设计

- 打蜡与天气互斥，前端使用同一个地图外观选项，后端也会拒绝冲突请求。
- 选择“下雨”会把天空选项重置为默认的 Train 阴天；随后可以另选天空。已保存的“下雨 + 指定天空”会被保留。这是现有界面行为，本次没有改动。
- 打蜡支持 Dust2、Ancient、Mirage、Nuke、Anubis、Inferno、Overpass、Cache。
- 雨天支持 Dust2、Ancient、Mirage、Nuke、Anubis、Inferno、Cache。Nuke 的验收方案只有雨，没有湿地面/水洼。
- 蓝绿幕的 10 个随包地图子包均可用本机官方资源成功构建。
- 前端当前不提供下雪。隐藏的 Dust2 下雪配置未达到 `validated` 状态，生产构建会明确拒绝；Train 的原生雨转雪粒子构建可通过。这不属于当前可选雨天功能。
- 自定义 KDA/伤害块当前在脚本中明确禁用，前端也隐藏了控件。虚拟按键音控件暂时隐藏，播放逻辑与按键 HUD 的可见状态关联。本次未擅自启用这些功能。
- 按键 HUD 需要 Demo 中可解码的 `svc_UserCmd` 数据。实际抽查中两份 Dust2 Demo 没有该数据；一份 Ancient Demo 成功提取 10 条玩家输入轨迹。缺少输入流时保留其他图层并隐藏按键面板。
